# rsnetwork

Networking for Rust: one sans-I/O protocol core for HTTP/1.1, HTTP/2, HTTP/3, and its own QUIC
transport, for clients and servers, with TLS through rustls and optional bindings for rsasync,
Tokio, or a caller-driven event loop.

Status: in development. There is no public API yet.

Develop with `cargo xtask fix`, `cargo xtask test`, and `cargo xtask check`.
